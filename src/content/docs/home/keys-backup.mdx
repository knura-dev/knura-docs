Every tag's keys are worked out from one **master key** in your settings folder. Your tags don't need a backup, but that folder does: without it you can't check, re-point or reset any tag you set up, and there is no way to get the key back.

:::tip[Using a hosted account?]
There's nothing to back up. Your hosted account keeps the master key encrypted on the server, and it can't be downloaded.
:::

## Check where you stand

```sh
knurctl backup
```

It shows your **master key ID** (a short name for the key that gives nothing away) and when you last made a backup file and a recovery sheet. knurd's log, `knurctl provision` and the app's **Server** tab remind you until you have one.

:::note[New command]
If `knurctl backup` says `unknown command`, update knurctl and knurd from the [latest release](https://github.com/knura-dev/knura/releases).
:::

## Two ways to back up

Do both if you can. They protect against different things.

| | Backup file | Recovery sheet |
| --- | --- | --- |
| Command | `knurctl backup create` | `knurctl backup sheet` |
| What it holds | Your whole settings folder: keys, action rules, secrets, phone logins, tap counts | Your master key and tap.knura.io key only |
| Locked by | A passphrase you choose | Nothing: it's paper, so keep it like a passport |
| Keep it | Off this computer: a USB stick you keep safe, or your password manager's file storage | With your important papers, away from the computer |
| Survives | A dead disk or a lost computer | All of that, and a forgotten passphrase too |
| After restoring | Everything works again | Write your rules again and pair your phones again |

### Make a backup file

From your settings folder (where `knurd.properties` is):

```sh
knurctl backup create
```

Choose a passphrase of at least 10 characters (a few random words work well) and keep it in your password manager. Without it nobody can open the backup, you included.

It writes `knura-backup-<date>.knurabackup` next to your settings folder, for example `~/knura/knura-backup-2026-11-01.knurabackup`. Logs are left out. Copy the file somewhere safe, then delete the local copy.

Check a copy at any time. This proves the passphrase works and that the copy holds the master key you use now:

```sh
knurctl backup verify ~/knura/knura-backup-2026-11-01.knurabackup
```

### Print a recovery sheet

```sh
knurctl backup sheet
```

This writes a one-page sheet you open in a browser and print. On Linux it goes to `/dev/shm`, which is in memory only, so it never lands on your disk. Print it on paper (not to a PDF), then delete the file as the command tells you.

The sheet shows each key as short rows like `3F9A 21C0 7B44 E2D1  5C`. The last two characters of each row are a check, so a typo is caught on the row it's in when you type the sheet back in.

:::caution[Never in plain sight]
Don't put the settings folder, the recovery sheet, or a photo of it in Git, a shared drive or a chat. Anyone with your master key can make your tags' links themselves.
:::

### When to back up again

Make a new backup after you:

- run `knurctl init` (a new master key: also print a new sheet and destroy the old one)
- run `knurctl resolver register` the first time (a new tap.knura.io key: also print a new sheet)
- change your action rules or secrets
- pair or remove a phone

Tap counts change with every tap, so an older backup is fine for them.

## Restore

### From a backup file

<Steps>

1. Install knurctl and knurd from the [latest release](https://github.com/knura-dev/knura/releases).

2. Restore into an empty settings folder:

   ```sh
   mkdir -p ~/knura/home && cd ~/knura/home
   knurctl backup restore ~/knura-backup-2026-11-01.knurabackup
   ```

   Every file comes back readable by you only. It never writes over an existing `knurd.properties`.

3. Start knurd from the folder and tap each tag once. You should see **Tap verified**. The first tap moves each tag's count past any link it made after the backup.

</Steps>

### From a recovery sheet

<Steps>

1. Install knurctl and knurd from the [latest release](https://github.com/knura-dev/knura/releases).

2. In an empty settings folder, type the sheet in:

   ```sh
   mkdir -p ~/knura/home && cd ~/knura/home
   knurctl backup restore --sheet
   ```

   Type each row as it is on the sheet, check characters included. Spaces don't matter. Check the master key ID it prints matches the one on the sheet.

3. Set `public.url` in the new `knurd.properties`, start knurd, and run `knurctl resolver register` if your sheet had a tap.knura.io part.

4. Tap each tag once. Then set up your [actions](/actions/webhooks) again and [pair your phones](/tags/set-up-with-phone) again.

</Steps>

## Move knurd to another computer

<Steps>

1. **Stop knurd on the old computer**, and keep it stopped. Two knurds with the same master key each keep their own tap counts, so a link used on one would still work on the other.

2. **Install knurd and knurctl** on the new computer from the [latest release](https://github.com/knura-dev/knura/releases), as in [Your first verified tap](/start-here/first-verified-tap) steps 1 and 2.

3. **Restore your settings folder** there from a backup file, as above.

4. **Give it a public address.** Set `public.url` in `knurd.properties` to the new computer's address, for example its own [Tailscale Funnel](https://tailscale.com/kb/1223/funnel) address.

5. **Send your taps to it.**
   - If your tags carry a **tap.knura.io** link, start knurd, then point tap.knura.io at the new address. The tags stay as they are:

     ```sh
     knurctl resolver register
     knurctl resolver check
     ```

   - If your tags carry the **old computer's address**, rewrite each one with `knurctl provision --from knura`, or with **Set up a tag** in the app with **Tag already has Knura keys** turned on.

6. **Pair phones again** if the new computer has another network address. Set `admin.listen.host` to it, restart knurd and run `knurctl admin pair-phone` with a new name. If the app says knurd's certificate isn't the one it was paired with, forget knurd in the app first. See [Set a blank tag up with your phone](/tags/set-up-with-phone).

</Steps>

Moving often? Register with tap.knura.io once. Tags then carry a link that never changes, and a move is one `resolver register` instead of rewriting every tag.
